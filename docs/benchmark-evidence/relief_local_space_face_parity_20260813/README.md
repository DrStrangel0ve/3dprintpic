# Local and Hugging Face relief face parity

This evidence addresses the August 13, 2026 report that an STL generated by
the Hugging Face Space had visibly flatter, damaged faces than the local
Next.js/FastAPI application.

No private photo is published here. The controlled reproduction uses the
checksum-pinned privacy-safe CC0 generated portrait from
`background_photo_detail_cc0_euclidean_guard_n3_dirty`:

- Source SHA256:
  `368b04492a8b73d749e14646fae757331705ee3b095df19df6ae4851846ff973`
- Model: `depth-anything/Depth-Anything-V2-Large-hf`
- Mesh preset: Bambu Lab P1S, 512 depth samples, 2x mesh multiplier
- Relief: 30 mm plus a 2.4 mm flat backing plate
- XY footprint/detail basis: 76/256 mm
- Face refinement: strength 1.0, feather 0.20, correction cap 0.08

## Reproduction

Before the fix, a same-input local/hosted 10 mm probe matched closely over
most of the surface but diverged around the face:

| Region | Z correlation | Mean absolute difference | P95 difference |
| --- | ---: | ---: | ---: |
| Complete surface | 0.99878 | 0.0393 mm | 0.1502 mm |
| Face | 0.98776 | 0.1705 mm | 0.8000 mm |

Package-version replay did not reproduce the hosted divergence. The old and
Space-compatible NumPy, SciPy, Pillow, OpenCV, and scikit-image stacks emitted
the same local surface. The remaining hardware-sensitive path was CUDA
`float16` inference, which was also used independently for each face crop.
The Space additionally relied on a home-directory cache for face detector and
shape-prior assets and opened at 10 mm while the local UI opened at 30 mm.

## Fix

The production relief contract now requires:

1. Lossless PNG browser handoff.
2. The same 30 mm default and physical request fields in both UIs.
3. Deterministic FP32 CUDA inference for the complete source and every face
   crop, with TF32 disabled and highest FP32 matmul precision selected.
4. Checksum-verified MediaPipe, YuNet, and GNM assets in an explicit writable
   runtime cache, plus loadable `libGLESv2.so.2` and `libEGL.so.1` supplied
   by Debian's `libgles2` and `libegl1` packages.
5. A fail-closed hosted parity audit for every face-bearing result, including
   full-scene reliefs: every detected face must be refined with at least 468
   MediaPipe landmarks and deterministic FP32 crop depth.

## First live deployment probe

Space commit `466c5bd26cffd1bf7f2c8324ba6ad81f89c5a409` completed the same
public 30 mm run in 103.164 seconds and emitted a clean, one-component,
watertight STL with 176,876 faces and a 32.7567 mm Z extent. Scene inference
correctly reported deterministic FP32, but face telemetry exposed the
remaining hosted-only defect:

`mediapipe:OSError:libGLESv2.so.2: cannot open shared object file`

The Space silently used `opencv-yunet-2023mar`, emitted zero MediaPipe
landmark faces, and therefore omitted the local 478-landmark shape prior.
The model files and checksums were all correct; the missing Linux shared
library was the causal deployment difference. The new native preflight and
full-scene face gate encode this exact failure as a regression contract.

After installing GLES, the fail-closed gate blocked a second live result before
publication because MediaPipe still could not initialize. Direct `DT_NEEDED`
inspection of the pinned official `mediapipe==0.10.35` Linux wheel showed that
`libmediapipe.so` links to both GLESv2 and EGL. The deployment therefore
preflights and records both native libraries.

## Local 3080 Ti validation

The paired FP16/FP32 30 mm run changed only the precision contract. FP32 kept
the existing local geometry while slightly improving the face agreement audit:

| Metric | FP16 control | FP32 candidate |
| --- | ---: | ---: |
| Face normal mean cosine | 0.991623 | 0.991816 |
| Minimum face lighting correlation | 0.922707 | 0.923514 |
| Maximum face lighting MAE | 0.023643 | 0.022017 |
| Refined faces / MediaPipe landmarks | 1 / 478 | 1 / 478 |

Direct FP16-to-FP32 surface agreement was 0.9999977 overall and 0.9999740 on
the face. Face Z MAE/P95 were 0.02803/0.09747 mm and face-gradient correlation
was 0.9997663. The FP32 STL had 176,816 faces, one watertight component, and a
32.7977 mm Z extent. Its cold local run completed in 24.422 seconds.
