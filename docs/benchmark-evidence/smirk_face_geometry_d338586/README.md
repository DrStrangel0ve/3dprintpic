# SMIRK face geometry evidence

This directory contains compact, privacy-safe evidence for implementation
commit `d338586419839b7af9590d1b8c5fbd65035bbace`.

No source photographs, meshes, model weights, FLAME assets, or private
artifacts are included. The evaluated corpus uses only CC0 MakeHuman geometry
and deterministic procedural scenes.

The full local evidence files were:

- Raw 32-row challenge: 6,345,415 bytes, SHA256
  `6e852e6a7e90ff3f5e9009ad692941a920524c4599c9652c4578fd1d93768377`.
- Three-row 30 mm replay: 1,413,586 bytes, SHA256
  `3f820f85f2a64d13f554518a4e653818cf8d005d34b71ec87e641ef503b4ad7c`.

The raw artifacts remain under ignored `backend/output` paths locally. The
compact JSON records the promotion decision, provider pins, split metrics,
physical printability, and validation state needed to audit the result.
